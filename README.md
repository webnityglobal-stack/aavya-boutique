# Aavya Boutique

A responsive multi-page boutique storefront built with React, Vite, Tailwind CSS and React Router.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL shown by Vite (usually http://localhost:5173).

## Pages
Home, Shop, Collections, About, Gallery, Contact and Product Details.

## Notes
- This is a frontend demo. Cart and contact interactions are local/demo interactions; no payment, inventory, email delivery or backend is connected.
- Product and editorial photos are loaded from Unsplash image URLs. An internet connection is required.
- Replace the sample boutique name, contact details, products, prices and media with your own brand assets before publishing.
